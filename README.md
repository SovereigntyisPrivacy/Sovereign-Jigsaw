# Sovereign Jigsaw

Jigsaw puzzle with no bs. 

A 100% offline, local-first jigsaw puzzle application built for Android via Termux/Capacitor. Designed as an ad-free alternative to mainstream mobile puzzle games.

## Core Features
- **Zero Telemetry & Offline Native:** No cloud servers, no data harvesting.
- **Custom Local Photos:** Select images directly from your device's local gallery.
- **Dynamic Slicing:** Generates interlocking bezier-curved tabs based on image aspect ratios.
- **Auto-Save:** Progress is saved automatically to local device storage.
